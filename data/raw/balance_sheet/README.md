# Balance-sheet source files

Drop all new balance-sheet `.xlsx` workbooks directly into this folder.

The importers select the newest workbook containing the worksheet required for
each commodity:

- Maize: `Maize`
- Wheat: `Data Table Wheat`
- Sunflowers: `Data Table SUN`
- Soybeans: `Data Table SOA`

Workbook filenames may include dates and do not need to follow one exact naming
pattern. Multiple commodity workbooks can remain in this folder together.
